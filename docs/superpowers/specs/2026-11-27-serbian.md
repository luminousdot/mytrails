# Serbian language

**Decision (27 Nov 2026):** Serbian in Latin script is the default language, English second. All five Serbian race sites we compared are in Serbian (see `docs/competitor-map.md`).

- **Routes:** every page lives under `/sr/…` or `/en/…` (`src/app/[lang]/`). `src/proxy.ts` redirects a path without a language: to the one in the `lang` cookie (set on every visit), else Serbian for browsers in a language of the region (sr, hr, bs, sh, cnr, me) or with none, else English. Uploads and GPX files are excluded.
- **Words:** `src/i18n/en.ts` defines the keys; `sr.ts` must match them (type-checked). Templates use `{n}`-style placeholders filled by `fill()`; counts use `plural()` with Intl plural rules (Serbian: one, few, other).
- **Formats:** dates, numbers and month names through `Intl` with `sr-Latn-RS` / `en-GB` (`formatDates`, `formatKm`, `formatGain`, `formatNumber`). Country names translate through the dictionary; data keeps the English name.
- **Switch:** SR / EN in the top bar keeps the current page.
- **Error messages:** the form's validation returns error codes; the screen shows them in the visitor's language.
- **Not translated:** race names and descriptions (they are the organisers' own), the map's gesture hint from MapLibre.

# Demo data

This folder is the prototype's demo dataset, frozen as crawled on 27 November 2026:

- `races.json`: 103 upcoming SE Europe races (ITRA, enriched with WST from mountain-race.rs)
- `sources/`: the raw crawler outputs `merge.py` combines
- `profiles/`: elevation points for the 7 races with a GPX track

Keep it as is for now. Re-running the crawlers would change dates, covers and counts the design work is checked against.
